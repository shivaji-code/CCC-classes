# C++ STL Algorithms Cheat Sheet

A quick reference for the most commonly used C++ STL algorithms from the `<algorithm>` and `<numeric>` headers.

---

## Sorting & Searching

### `sort()`
- Sorts the elements in ascending order by default.

### `reverse()`
- Reverses the order of elements in a range.

### `find()`
- Finds a specified element in a range.

### `count()`
- Counts how many times a value appears in a range.

### `binary_search()`
- Checks whether an element exists in a sorted range.

### `lower_bound()`
- Returns the first position where the value is **greater than or equal to** the given value.

### `upper_bound()`
- Returns the first position where the value is **greater than** the given value.

---

## Maximum & Minimum

### `max()`
- Returns the larger of two values.

### `min()`
- Returns the smaller of two values.

### `max_element()`
- Returns an iterator to the largest element in a range.

### `min_element()`
- Returns an iterator to the smallest element in a range.

---

## Rearranging Algorithms

### `swap()`
- Exchanges the values of two variables.

### `next_permutation()`
- Rearranges elements into the next lexicographically greater permutation.

### `prev_permutation()`
- Rearranges elements into the previous lexicographically smaller permutation.

### `rotate()`
- Rotates elements so that a chosen element becomes the first.

### `reverse()`
- Reverses the order of elements in a range.

---

## Duplicate Handling

### `unique()`
- Removes consecutive duplicate elements from a sorted range.

---

## Filling & Copying

### `fill()`
- Assigns the same value to all elements in a range.

### `copy()`
- Copies elements from one range to another.

### `merge()`
- Merges two sorted ranges into one sorted range.

---

## Comparison & Mathematics

### `equal()`
- Checks whether two ranges contain the same elements in the same order.

### `accumulate()`
- Computes the sum (or custom accumulation) of elements in a range.

### `gcd()`
- Returns the Greatest Common Divisor (GCD) of two integers.

---

## Required Headers

```cpp
#include <algorithm>   // sort, reverse, find, count, binary_search, etc.
#include <numeric>     // accumulate, gcd
```
